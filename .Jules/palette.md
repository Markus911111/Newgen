## 2025-01-29 - [Lazy Validation Pattern]

**Learning:** Using `input:not(:placeholder-shown):invalid` allows us to show error states only _after_ the user has interacted with the field, preventing initial "red scary form" syndrome without complex JS.
**Action:** Use this CSS-only pattern for simple form validation feedback in future forms.

## 2026-01-31 - [Context-Aware Spinner]
**Learning:** Using `currentColor` for CSS spinners ensures loading states automatically match the button's text color, maintaining contrast and visual consistency without extra code.
**Action:** Use this pattern for all button loading states to ensure accessibility on different background colors.
